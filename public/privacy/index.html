Privacy Policy

What this site collects, and what it never will.

The short version

No analytics, no trackers, no ads, no third-party cookies, no selling data. The only things stored are the conversations you start and the messages you ask the agent to pass along.

What is stored

  • Chat conversations. Messages you send the on-site agent are stored server-side under a random session id so your history can replay when you return. Ask for a session to be deleted via the contact form and it will be.
  • Contact messages. When you ask the agent to send Paul a message, the name, contact detail, and message you provide are stored until read.
  • Rate-limit counters. To prevent abuse, the site keeps a daily counter keyed by a SHA-256 hash of your IP address. The raw IP is never stored, and counters are deleted the next day.

Cookies

One first-party cookie, flue_session: a random UUID your own browser generates, used solely to resume your chat session. It is not sent anywhere else and tracks nothing.

Processors

  • Cloudflare hosts the site and runs the agent. Chat messages are processed by a Llama model on Cloudflare Workers AI to generate replies.
  • GitHub — the agent's "recent activity" comes from the operator's public GitHub events feed. This is public data about the site operator, not about you.

Your choices

Clear your cookies to start a fresh session. To have a conversation or contact message deleted, use the contact form on the home page and say so — this site publishes no email address to scrape.

Changes

This policy is versioned with the site itself; the history is public in the source repository. Last updated: 2026-10-10.
